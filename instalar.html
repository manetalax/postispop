Abre PostisPop desde la pantalla de inicio o el escritorio. Usa tu cuenta para acceder a tus notas sincronizadas.

Elige tu dispositivo para ver cómo instalar la versión web.

iPhone y iPad

Instalación web

  1. Abre PostisPop en Safari.
  2. Pulsa Compartir y «Añadir a pantalla de inicio».
  3. Activa «Abrir como app web» si aparece y confirma.
Ayuda de Apple

Versión de App Store pendiente.

Android · móvil y tablet

Instalación web

Abre PostisPop en Chrome. Usa el botón de instalación cuando aparezca o busca «Instalar aplicación» / «Añadir a pantalla de inicio» en el menú.

La APK de distribución está pendiente de firma y pruebas. No hay todavía una descarga pública.

Windows

Instalación web

Abre PostisPop en Chrome y selecciona la opción de instalar la página como aplicación en su menú. También puedes usar el botón de instalación cuando esté disponible.

Instalador nativo pendiente.

macOS

Instalación web

Abre PostisPop en Chrome y utiliza la opción de instalar la página como aplicación. El acceso aparecerá entre tus aplicaciones.

Paquete nativo para Mac pendiente.

Linux

Instalación web
